# GCTU Student Hub

A student productivity website for organising university life: timetable,
assignments, study tasks, GPA calculator, exam countdown and notes.

> Unofficial student learning project. Not affiliated with GCTU.
> Any example information shown in the app is sample data.

## Run it locally

Double-click `index.html` to open it in your browser (Chrome, Edge or Firefox).
No installation is needed for this first version.

## Project structure

```
index.html      Page structure
css/styles.css  Colours, layout and responsive design
js/app.js       JavaScript that runs the page
```
